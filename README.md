# Power BI Retail Sales Dashboard

## Overview
This project analyzes retail sales performance using the Sample Superstore dataset. 
The dashboard provides insights into sales trends, profit margins, product performance, 
and customer segmentation.

## Key Features
- Total Sales, Profit, Orders and Profit Margin KPIs
- Monthly Sales and Profit Trends
- Sales by Product Category
- Top 5 Products Analysis
- Revenue Distribution by Customer Segment
- Sales Distribution by State
- Sales Forecasting using Power BI

## Tools Used
- Power BI
- DAX
- Data Visualization

## Dataset
Sample Superstore Dataset

## Insights
- Technology category generates the highest sales.
- Consumer segment contributes the largest share of revenue.
- Sales increase significantly during November and December.
